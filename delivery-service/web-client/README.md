# Web Client - Интерфейс отслеживания заказа

## Описание
Веб-интерфейс для клиентов для отслеживания статуса заказа и местоположения курьера.

## Структура

### Components (Компоненты)
- `OrderTracking.js` - Главный компонент отслеживания
- `Map.js` - Компонент карты
- `StatusIndicator.js` - Индикатор статуса заказа
- `OrderInfo.js` - Информация о заказе
- `Timeline.js` - Временная шкала статусов

### Services (Сервисы)
- `apiService.js` - Работа с API
- `mapService.js` - Работа с картами

## Основные функции

### Отслеживание заказа
- Ввод номера заказа
- Получение информации о заказе
- Автообновление данных

### Карта
- Отображение местоположения курьера (эмуляция)
- Маркер ресторана
- Маркер адреса доставки
- Построение маршрута

### Статусы заказа
- Создан
- Назначен курьеру
- В пути
- Доставлен

### Визуализация
- Цветовое кодирование статусов
- Анимация перемещения курьера
- Временная шкала

## Технологии
- HTML5, CSS3, JavaScript
- Leaflet / Google Maps API
- React / Vue.js (опционально)
