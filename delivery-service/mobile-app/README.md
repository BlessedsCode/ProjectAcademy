# Mobile App - Приложение для курьера

## Описание
Мобильное приложение для курьеров сервиса доставки еды.

## Структура

### Screens (Экраны)
- `LoginScreen.js` - Экран авторизации
- `OrdersListScreen.js` - Список заказов курьера
- `OrderDetailScreen.js` - Детали заказа
- `ProfileScreen.js` - Профиль курьера

### Components (Компоненты)
- `OrderCard.js` - Карточка заказа
- `StatusButton.js` - Кнопка изменения статуса
- `Header.js` - Заголовок приложения
- `LoadingSpinner.js` - Индикатор загрузки

### Services (Сервисы)
- `apiService.js` - Работа с API
- `authService.js` - Авторизация
- `locationService.js` - Геолокация

### Navigation
- `AppNavigator.js` - Основная навигация приложения

## Основные функции

### Авторизация
- Вход курьера в систему
- Хранение токена авторизации

### Список заказов
- Отображение назначенных заказов
- Фильтрация по статусам
- Обновление списка

### Детали заказа
- Адрес доставки
- Контакты клиента
- Описание заказа
- Кнопки изменения статуса

### Изменение статуса
- "Принят"
- "В пути"
- "Доставлен"

### Push-уведомления
- Уведомление о новом заказе

## Требования
- React Native / Flutter
- Android 8.0+
- iOS 12.0+
