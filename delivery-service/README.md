# Сервис доставки еды — Модуль курьера и отслеживания заказа

## Описание проекта
Мобильное приложение для курьеров и веб-интерфейс для отслеживания заказов в сервисе доставки еды.

## Технологический стек

### Backend
- Язык: Node.js / Python / Java (на выбор)
- База данных: PostgreSQL / MySQL / MongoDB
- Framework: Express.js / FastAPI / Spring Boot

### Mobile приложение
- React Native / Flutter
- Поддержка: Android 8.0+, iOS 12.0+

### Web клиент
- HTML5, CSS3, JavaScript
- Библиотека карт: Leaflet / Google Maps
- Framework: React / Vue.js (опционально)

## Основные функции

### Backend API
- Управление заказами (CRUD)
- Управление курьерами
- Изменение статусов заказов
- Эмуляция геолокации
- Аутентификация

### Mobile приложение (Курьер)
- Авторизация
- Просмотр списка заказов
- Изменение статуса заказа
- Отправка геолокации

### Web интерфейс (Клиент)
- Отслеживание заказа
- Карта с местоположением курьера
- Визуализация статусов
